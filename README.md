# Road Damage Classification Using CNN
## Project Overview

This project uses a Convolutional Neural Network (CNN) to classify road images into different categories such as:

- Crack
- Normal
- Pothole

The model was developed using Python and TensorFlow/Keras in Jupyter Notebook and deployed as a desktop application using Python Tkinter in Spyder.

## Objective

To develop a deep learning model that can automatically classify road conditions from images and identify common road damage such as cracks and potholes.

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Tkinter
- Jupyter Notebook
- Spyder

## Project Workflow

1. Dataset collection
2. Image preprocessing
3. Train-test split
4. Image normalization
5. CNN model development
6. Model training
7. Model evaluation
8. Prediction
9. Model saving
10. Deployment using Tkinter

## CNN Model

The CNN consists of:

- Convolutional layers
- ReLU activation
- Max Pooling
- Flatten layer
- Dense layers
- Softmax output layer

## Classes

The model classifies images into:

- Crack
- Normal
- Pothole

## Model Evaluation

The model was evaluated using:

- Accuracy
- Loss
- Confusion Matrix
- Classification Report
- Precision
- Recall
- F1-score

## Deployment

The trained model was saved as:

`road_damage_cnn_model.keras`

A Python Tkinter application was developed to allow users to select a road image and obtain the predicted road damage class.
